# Canvas demos

Three inline canvas generative pieces. Pure browser, no framework, no build.

1. **Orbital trace** — 80 dots on a hue-cycling ring
2. **Flow field** — particles drift through a Perlin-like vector field
3. **Truchet tiles** — random arc-tiles compose into looping textures

## Run

Open `index.html` in a browser. That's it.

Click any canvas to restart / redraw.
